As mentioned in the intro, I built this website to showcase some of my projects and experiences throughout my journey as a software engineer.

It was created with [React](https://react.dev) and [TypeScript](https://www.typescriptlang.org), bundled with [Vite](https://vitejs.dev), and styled using [MUI](https://mui.com) alongside vanilla CSS. I've always loved the aesthetic of the [Nord theme](https://www.nordtheme.com) (I first fell in love with it on my Linux machine) so it felt like a natural fit for a personal site. Animations are handled by [Framer Motion](https://www.framer.com/motion/), and content is written in Markdown to keep things easy to maintain.
